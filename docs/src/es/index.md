# Productive K3S Catalogs

Productive K3S Catalogs es el punto público de descubrimiento para contenido instalable de Productive K3S.

Usá este sitio para:

- recorrer profiles de infraestructura publicados;
- recorrer add-ons y stacks publicados;
- inspeccionar los metadatos de marketplace expuestos a `pk3s`;
- entender el formato normalizado de catálogo que consumen las automatizaciones.
