# Product

The catalogs site is the public discovery layer for the Productive K3S ecosystem.

It does not implement scenarios, profiles, add-ons, or stacks itself. Instead, it publishes the normalized catalog indexes generated by `productive-k3s-ops` and renders them as a marketplace-style website.

Use the product pages to:

- browse the live marketplace entries;
- understand which package types are publicly exposed;
- review the catalog contract that `pk3s` consumes.
